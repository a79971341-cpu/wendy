# 냥이 건널목

고양이를 움직여 차도, 강, 기찻길을 건너 최대한 멀리 가는 길건너기 게임입니다. `index.html` 파일 하나로 동작하며, 브라우저에서 열면 바로 할 수 있어요.

## 조작
- 키보드: 방향키 또는 WASD (M: 소리 켜기/끄기)
- 휴대폰: 탭하면 앞으로, 스와이프로 방향 이동

## 규칙
- 앞으로 간 칸 수가 점수예요.
- 차와 기차에 부딪히면 끝. 강에서는 통나무나 연잎 위로만 뛸 수 있어요.
- 기찻길에 빨간 불이 깜빡이면 곧 기차가 와요.
- 한자리에 오래 있으면 멍멍이가 쫓아와요.
- 생선을 모아 턱시도, 고등어, 삼색이, 샴, 까망이를 입양할 수 있어요. 기록과 생선은 브라우저에 저장됩니다.
