# 냥이 건널목

고양이를 움직여 차도, 강, 기찻길을 건너 최대한 멀리 가는 픽셀 길건너기 게임입니다. `index.html` 파일 하나로 동작하며, 브라우저에서 열면 바로 할 수 있어요.

## 조작
- 키보드: 방향키 또는 WASD (M: 소리 켜기/끄기)
- 휴대폰: 화면 아래 방향 버튼, 화면 탭(앞으로), 스와이프

## 규칙
- 앞으로 간 칸 수가 점수예요.
- 차와 기차에 부딪히면 끝. 강에서는 통나무나 연잎 위로만 뛸 수 있어요.
- 기찻길에 빨간 불이 깜빡이면 곧 기차가 와요.
- 한자리에 오래 있으면 멍멍이가 쫓아와요.
- 치즈와 루이(페르시안 친칠라)는 처음부터 고를 수 있고, 생선을 모아 턱시도, 고등어, 삼색이, 샴, 까망이를 입양할 수 있어요. 기록과 생선은 브라우저에 저장됩니다.

## 글꼴
화면 글씨는 [갈무리11](https://github.com/quiple/galmuri)(SIL OFL 1.1, `fonts/Galmuri-OFL.md`)을 쓰며, 페이지에 쓰인 글자만 잘라 `index.html` 안에 넣었습니다.
화면 문구를 바꾼 뒤에는 글꼴을 다시 넣어 주세요.

```sh
pip install fonttools brotli
npm pack galmuri && tar xzf galmuri-*.tgz
python3 tools/embed_font.py package/dist
```
